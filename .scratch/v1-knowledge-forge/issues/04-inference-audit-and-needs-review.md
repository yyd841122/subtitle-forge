# 04 — 推理审计与待复核语义

**What to build:** 端到端运行后，"引用真实存在但断言超出引用支持范围"的知识单元被推理审计拒绝、不进入可信发布集，缺口报告记录拒绝原因。审计环节无法可靠判定通过或拒绝时，该单元进入待复核状态——带明确理由记录，不是"低质量"兜底。"低可信"只作为风险信号，用于触发待复核或提高抽查优先级，不构成独立状态。

**Blocked by:** 03 — 忠实性审计与可信发布集门（推理审计叠加在忠实性比对通过的单元上：引用真实才有"断言是否超出支持范围"可审）。

**Status:** ready-for-agent

- [ ] A2 推理审计：注入"引用真实存在但断言超出引用支持范围"的单元（替身），运行后该单元不进入可信发布集，缺口报告记录拒绝原因
- [ ] A14 待复核语义：注入"审计替身返回不确定结论"的单元，该单元实体状态为待复核（不进入可信发布集），运行摘要有其下落，且待复核有明确理由记录——不是因为"低质量"被兜底（R4.4）
- [ ] 推理审计作为独立认知环节与提炼分离（R3.2、R3.4；是否使用不同模型不是产品要求）
- [ ] "低可信"以风险信号形态存在：触发待复核或提高抽查优先级，不新增独立状态或领域术语（R3.8）
- [ ] 拒绝/待复核/失败三种实体状态在外部产物中语义不混用（R4.6）

> 实现决策（本票裁定并记录 ADR）：推理审计替身的行为协议；风险信号的表达形式。
