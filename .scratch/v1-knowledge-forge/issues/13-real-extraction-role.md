# 13 — 真实提炼角色接入

**What to build:** 提炼认知角色（知识单元抽取、聚合、覆盖自检信号、疑点信号）由真实 AI 模型承接：在真实模型驱动的一次运行中，产出结构完整、可审计的候选知识单元与候选 Source Reference——候选引用的有效性结论仍由 03 票的程序忠实性审计产生，提炼不自行宣告"有效"。本票职责是**集成与 smoke**：真实角色与替身可在同一运行中互换，端到端产品级断言不因接入真实模型而失效；真实语义质量做有界、非默认的 smoke 验证，不作为完成条件。

正式验收（A1–A22）全部在确定性替身接缝上完成（01–12、15 票）；本票不新增默认验收条件，不把真实模型的语义表现固化为验收 oracle。

**Blocked by:** 07 — 聚合知识层与审计尺度分离（真实提炼要产出聚合层）；09 — Review Note 与忠实层不可篡改（真实提炼只产生疑点信号，不产出正式 Review Note）；10 — 版本化再生（提示词属规则，其变化走新版本重生成——完成项引用 10 的语义）；12 — 成本可观察、受限运行与真实调用计量契约（真实调用的 usage/cost 经计量契约进入运行摘要）。

**Status:** ready-for-agent

- [ ] 真实提炼产出候选 Source Reference：结构完整（原文文本片段 + 定位信息），可被忠实性审计程序比对；有效性结论来自审计，不来自提炼（候选语义，非"有效"宣告）
- [ ] 真实提炼产出分层结构（知识单元 → 要点/主题 → 概要），聚合知识不携带单元级实体状态
- [ ] 真实提炼可产生覆盖自检信号，但不作为最终覆盖结论（裁决 3）；疑点以信号形态传递，不直接落为正式 Review Note（裁决 4）——信号与审查结论的分离契约由 09 票的断言保障
- [ ] 与替身互换兼容：同一运行中把提炼角色从替身切换为真实模型（或反之），端到端断言（审计门、对账、状态枚举）不失效
- [ ] 真实调用计量：真实模型的 usage/cost/latency 经 12 票契约进入运行摘要，无需改造计量代码（R7.1 对真实调用成立）
- [ ] 真实提炼 smoke（非默认、有界）：小型受控 fixture（含噪声）上，真实提炼产出合法结构、引用可被程序比对、处理不失败；不设不可重复的语义质量门槛
- [ ] 中文为主的语料下正常工作；产品设计不锁死语言（R1.4 的语言半）——smoke 范围
- [ ] 提示词与结构化输出（Open Impl 11）作为可迭代资产管理，修改提示词属规则变化，走新版本重生成（与 10 票的版本化再生语义一致）

> 实现决策（本票裁定并记录 ADR）：提炼模型选择与提示词设计（Open Impl 11）；结构化输出方式；语言处理策略；smoke fixture 的规模与内容选择。
