# 14 — 真实审查角色接入

**What to build:** 审查认知角色（推理审计、覆盖审计、Review Note 确认，含聚合层质量审查——若 07 票裁定 V1 实际运行）由真实 AI 模型承接：对 13 票真实提炼产出的候选知识单元执行推理审计与覆盖审计，确认并产出正式 Review Note。本票职责是**集成、smoke 与校准**：真实审查角色返回合法可解析的结果，管线按其实际 verdict 正确路由，端到端断言不因接入真实模型而失效；真实数据下的指标校准（08 票标记的可替换指标）在此进行。**真实模型的语义质量不是本票完成条件**——verdict 的判定语义已由确定性替身在 01–12 验证，本票验证的是真实路径的接线与合法性。

正式验收（A1–A22）全部在确定性替身接缝上完成；本票不新增默认验收条件，不把真实模型的语义判定固化为验收 oracle——确定性替身已验证的是管线的判定语义，真实模型验证的是接线与合法性。

**Blocked by:** 07 — 聚合知识层与审计尺度分离；09 — Review Note 与忠实层不可篡改（两票建立审查职责的产物与断言）；08 — 覆盖审计独立性与指标成对（覆盖审计与 Review Note 确认的对象结构）；12 — 成本可观察、受限运行与真实调用计量契约（真实调用计量）；13 — 真实提炼角色接入（真实审查作用于真实提炼的候选产物，不自行假设其输出——否则只能审契约 fixture）。

**Status:** ready-for-agent

- [ ] 真实角色结果合法可解析：真实审查角色在受控 fixture 上返回合法、可程序解析的审查结果（verdict / 理由 / 引用结构符合 01 票建立的角色契约）——不要求命中任何特定语义结论
- [ ] 按实际返回路由：管线按真实角色**实际返回**的 verdict 正确路由——返回拒绝则单元不进可信发布集且缺口报告有"审计拒绝"，返回不确定则待复核带理由，返回确认则 Review Note 产出且与忠实层分离，返回覆盖存疑则缺口报告有条目；每个分支的外部表现与替身路径同一断言一致（verdict 的语义判定本身由替身验证，本项验证真实 verdict 的路由接线）
- [ ] 归属语义在真实路径下不回退：覆盖结论来自审查环节（非提炼自评）、Review Note 由审查环节产出、提炼疑点不自动升级为结论——以"信号与审查结论可区分"的结构断言验证（09/08 票断言在真实路径下复跑不失效）
- [ ] 聚合层质量审查（若 07 票裁定 V1 运行）：真实执行者在本票接入，结论不改变单元级实体状态
- [ ] 与替身互换兼容：同一运行中把审查角色从替身切换为真实模型（或反之），端到端断言（审计门、对账、指标成对）不失效
- [ ] 真实调用计量：审查角色的真实 usage/cost/latency 经 12 票契约进入运行摘要（R7.1 对真实调用成立）
- [ ] 可选的真实模型端到端冒烟测试：确定性替身之外保留一个真实模型全链路冒烟（不进默认验收），验证真实 AI 环节的接线（Testing Decisions）
- [ ] 指标校准：以真实运行数据校准 08 票的暂定指标形式（可信性指标与知识覆盖指标的计算方式），校准结果记录为可迭代的规则（规则变化走新版本重生成，与 10 票语义一致）

> 实现决策（本票裁定并记录 ADR）：审查模型选择与提示词设计（Open Impl 11，是否与提炼使用不同模型不是产品要求）；结构化输出方式；校准方法与流程。
