# 15 — 资产可移植性、唯一规范源与衍生层边界

**What to build:** 规范知识资产是可移植、可独立保存的文件资产：把资产目录复制到另一空环境（指没有原系统的运行状态/数据库/缓存——不排除运行标准解析器所需的环境依赖），人可直接阅读，程序可解析出结构（知识单元、来源引用、实体状态、资产版本归属）且与解析工具无耦合。存在唯一规范数据源，索引/缓存等派生表示删除后可由规范源重建、知识无损，不存在双向漂移通道。跨 Source 关系与检索结构作为衍生层独立组织，可整体删除重算，基础层与可信发布集不受影响。

**Blocked by:** 06 — 全量对账与缺口报告一等资产；07 — 聚合知识层与审计尺度分离；09 — Review Note 与忠实层不可篡改（可移植性断言的对象——含状态、聚合层、审查层分离的完整资产——在这三票后成型）；10 — 版本化再生（唯一规范源与可移植断言建立在版本化产物之上，含多版本可区分的归属指认；避免在版本化之前固化 canonical 布局）。

**Status:** ready-for-agent

- [ ] A8 资产可移植性：将规范资产目录复制到另一空环境（无原系统状态/数据库/缓存；允许标准环境依赖），人可直接阅读资产内容；程序可解析出结构（知识单元、来源引用、实体状态）且与解析工具无耦合；删除派生的索引/缓存后可重建，知识无损（R6.1）
- [ ] A21 唯一规范源：对同一知识内容，规范数据源唯一；由它派生的其他表示（展示/索引/衍生结构）删除后可由规范源重建，且重建不改变规范源本身；不存在"修改派生物而规范源不知情仍一致"的双向漂移通道（R6.6）
- [ ] A10 衍生层隔离（二选一，实现裁定后不得再改分支）：删除/重算衍生层，基础层（按 Source 的资产）不受影响，可信发布集不变（R2.6、R2.7、R6.5——衍生层边界明确、可整体重算、不反向污染基础层，V1 不要求完整衍生知识能力）。分支 A——衍生层非空：至少存在一个最小但非空的派生产物（如最简索引或跨 Source 结构雏形），其删除/重建路径被实际验证；分支 B——衍生层为空：在票内记录裁定与理由（裁决 5 允许），验收为"边界存在且重建通道可演示"（以规范源重建派生表示的通道在测试中实际走通）
- [ ] 基础知识资产与 Source 明确对应（R6.4）；索引与缓存可删除、可重新生成（R6.2）；索引/缓存技术（Open Impl 8）由本票唯一裁定
- [ ] 人和机器都是一级消费者：人直接可读、机器可程序化解析结构（R6.3）
- [ ] 规范源格式选型（Open Impl 7——人可读为主 + 结构内嵌、还是结构文件为主 + 可读派生，及其他文件形态）由本票最终裁定并验收；01 票的初始形态若与本票裁定冲突，在本票内完成迁移

> 实现决策（本票裁定并记录 ADR）：规范源格式选型（Open Impl 7 最终裁定）；索引/缓存技术（Open Impl 8）；衍生层的具体组织方式（V1 允许为最小，非空转验收）。
