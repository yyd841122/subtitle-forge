# 15 — 跨版本切换与共存

**What to build（单一产品增量）:** 对已有资产目录以新版本运行 → 切换至新版本：全量重生（无跨版本跳过）、全部产物带新版本标识、切换过程不出现混版本产物；旧版本可同时指认（「这是哪一版标准的产物」）。

**Spec anchors:** R5.4、A20（完整：新旧可同时指认 + 同版本无混杂）。

**Blocked by（硬依赖）:** 14。

**Status:** open（2026-09-02 materialized）

**Materialized from:** plan v2.2 票 13b（ADR-0007）

**Acceptance（端到端断言，只对外部产物）:**
- [ ] v1 运行后以 v2 重跑同一资产目录 → 新产物全量重生且带 v2
- [ ] v1 的产物仍可指认（共存物理形态票内裁定）
- [ ] 切换中间态不存在可见的混版本产物（原子切换或票内裁定的等价保证）

**Implementation / code anchors:** 14 的版本字段；快照/产物的目录组织（共存形态的落点）。

**Spec 覆盖责任:** A20（完整）；R5.4。
