# 09 — Review Note 与忠实层不可篡改

**What to build:** 端到端运行后，对可疑内容（如"疑似口误""与常识冲突"）产生正式 Review Note——由审查环节确认并产出，明确标注为系统判断、与忠实层分离存放。提炼阶段可以发现疑点，但疑点只是信号，不得直接落为正式 Review Note。忠实层内容在任何环节都不被系统修改——"原文说的"与"系统认为的"永远可区分。

**Blocked by:** 01 — 单 Source walking skeleton（替身角色注入契约已建立）。可与 03/04 并行——Review Note 确认不需要 Needs Review 状态或忠实性审计先存在。

**Status:** ready-for-agent
