# 0002 — 忠实层与审查层分离，忠实层不可被系统修改

已接受（2026-09-01，grilling R2 确认；2026-09-01 审查修订：术语轴定名，"来源层"→"忠实层"，"第一层"→"基础层"）。

课程/访谈语料中说话人自己会说错（口误、过时结论、随口数字）。**决策：忠实层忠实表达来源内容，审查层独立产生审查注记（Review Note）**——系统对来源内容的评价提示（"疑似口误""与常识冲突"），明确标注为系统判断、与忠实层知识分离。V1 不要求系统判断外部世界事实真伪；**系统不得因怀疑内容错误而修改忠实层内容**（不允许"偷偷改对"）。

资产中有两个正交的分离维度，不得混用：**忠实层/审查层**（按"谁说的"分离：来源内容 vs 系统判断）与**基础层/衍生层**（按 Source 作用域分离：每 Source 独立成立 vs 跨 Source 关系）。后者同样遵守分离纪律：衍生层承载跨 Source 的重复/关联/深化/矛盾，可整体重算，不得反向污染基础层。（"来源层"一词停用——易与 Source 作用域维度混淆。）

后果：资产中"原文说的"与"系统认为的"永远可区分——这是可信审计能成立的结构前提；Review Note 质量问题最坏只需重算注记层。

## 备择方案

- 提炼时过滤可疑内容：违反忠实性定义，过滤错误不可恢复。
- 只照录不标注：资产传播说话人错误，损害知识库价值。
- 系统修正忠实层内容：信任模型崩塌，红线。
