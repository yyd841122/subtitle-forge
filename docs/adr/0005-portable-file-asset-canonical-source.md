# 0005 — 规范资产为可移植文件资产，唯一规范数据源

已接受（2026-09-01，grilling R3 确认；2026-09-01 审查修订：删除 Git/Markdown 等具体格式暗示，保留可移植性原则的抽象表述）。

资产要同时服务人和 AI 两类一级消费者，且可检索、可继续加工。**决策**：规范知识资产必须是**可移植、可独立保存的文件资产**；运行时允许存在可删除、可重新生成的索引与缓存，但它们不是规范资产。

"不依赖任何数据库/索引"的更强表述被有意放宽：禁止一切派生结构会损害可检索性。放宽的代价由**唯一规范数据源（Canonical Source）**规则兜底——必须存在唯一的权威表示，其他表示（索引、展示、衍生结构）一律由它派生且可重建，避免多个表示之间双向漂移。**哪种文件形态作为规范源属于实现决策**，验收条件是可移植与可独立保存，不预设具体格式。

配套要求：基础知识资产与 Source 保持明确对应（幂等重算的物理基础）；跨 Source 关系与检索结构属于可重建的衍生层（与 ADR-0002 的基础层/衍生层分离一致）。可移植性保证资产独立于工具存活，唯一规范源保证衍生物永不与本体打架。
